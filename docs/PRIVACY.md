# Public pseudonym and private financial identity

The public maintainer is `arinborgamer`; author metadata should use the account's GitHub noreply email. Before each release, inspect staged files and Git history for names, emails, source paths, credentials, logs and customer data. The repository does not need government ID, PAN, Aadhaar, bank details or a personal address.

Being pseudonymous in this repository does not guarantee that a GitHub profile or historical activity cannot link to a real identity. Existing public profile/history is outside this project's control and should be reviewed separately by its owner.

An Indian payment-provider account requires truthful private identity/business verification and an eligible bank account. Razorpay onboarding is a separate owner task. The checkout and invoices may show verified merchant details; inspect test checkout/receipts and use an approved business/brand name where supported. Do not invent a legal identity or assume the checkout hides it. [Razorpay onboarding](https://razorpay.com/docs/payments/international-payments/?preferred-country=IN), [GitHub noreply addresses](https://docs.github.com/en/account-and-profile/reference/email-addresses-reference).

Generated PDFs use the project name for author metadata. Local sources, captions, prompts, customer records and receipts remain under ignored runtime storage. The public license covers original project code and examples, not third-party reference material. There is no telemetry or model-provider cloud upload by default; choosing a remote Ollama endpoint sends the supplied brief there.
