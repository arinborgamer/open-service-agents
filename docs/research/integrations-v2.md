# Primary-source integration notes

Checked 2026-09-11. These are implementation contracts, not evidence of live account compatibility.

- **YouTube discovery:** `search.list` supports channel-only queries and bounded result pages; `channels.list` supplies public snippets/statistics. The implementation makes one bounded search and one batched detail request, with no invented email field. Credentials and quota remain the operator's responsibility. [Search API](https://developers.google.com/youtube/v3/docs/search/list), [Channels API](https://developers.google.com/youtube/v3/docs/channels/list).
- **Brave:** web search uses the official endpoint with an API subscription key. Search descriptions are snippets; retrieving a source is a distinct, permission-aware operation. [Brave documentation](https://api-dashboard.search.brave.com/app/documentation/web-search/get-started).
- **IMAP:** use TLS, select the mailbox read-only, operate with UIDs and preserve UIDVALIDITY across resumptions. `BODY.PEEK` avoids marking messages read. Only an exact outgoing-thread reference plus matching recipient permits body import, and reply text remains untrusted data. [Python IMAP client](https://docs.python.org/3/library/imaplib.html), [IMAP4rev2 RFC](https://www.rfc-editor.org/rfc/rfc9051.html).
- **Razorpay Route:** transfers can originate from captured payments to Linked Accounts, with INR amounts and optional settlement holds. Creating a transfer is separate from its later settlement; the transfer entity exposes distinct transfer and settlement states. Our adapter uses an explicit review/enable boundary, records uncertain outcomes, and does not claim settlement from submission. Account onboarding, live sandbox verification and reversal/reconciliation remain necessary. [Payment transfers](https://razorpay.com/docs/api/payments/route/create-transfers-payments/?preferred-country=IN), [Transfer entity](https://razorpay.com/docs/api/payments/route/transfers-entity), [Route prerequisites](https://razorpay.com/docs/api/payments/route/?preferred-country=IN).

Website/caption import is bounded public retrieval, not authority to republish another creator's work. The code offers manual permissioned notes when access is unavailable rather than bypassing paywalls, logins or crawler restrictions.
