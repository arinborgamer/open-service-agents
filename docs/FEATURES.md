# Evidence-to-implementation map

Read the full caption-study notes before treating narrated marketing as a technical specification. Complete captions for all four videos were studied; visual-only interfaces were not independently verified.

| Publicly narrated module | Original implementation | Present limitation |
|---|---|---|
| Synthesize niche ideas | `opportunity` stage plus optional live search discovery | Model suggestions use supplied evidence; no proprietary scores or guaranteed demand |
| Synthesize creator mode | Creator shortlist, public channel discovery, website/caption imports and `creator` analysis | No private Instagram scraping or proprietary performance data; rights review still required |
| Transformation map | `transformation` stage and 3-12 chapter count | No interactive AI outline-variant picker |
| Manuscript and branding | Up to 12 chapter stages, `brand`, draft editing and revision history | Editorial drafts; no guarantee of subject expertise |
| Ebook download | Markdown/HTML/ZIP and optional ReportLab PDF | PDF not included in buyer ZIP by default; not a 45-page reproduction |
| Store copy and publication | Editable/reorderable page sections, offer/sample/confirmation routes, product approval and Razorpay checkout | Single operator; public hosting and approved merchant still required |
| ListKit outreach | Discovery adapters, shortlist, A/B draft campaigns, per-message approval, SMTP, correlated read-only IMAP sync, suppressions and metrics | Own API/mail credentials; no private creator database or statistically validated autonomous optimization |
| Whop checkout and delivery | Signed events, revocable downloads, transactional email, explicit approval of Route share transfers | Provider/Linked Account onboarding and live tests required; submission is not bank settlement; reversals need reconciliation |
| Salesfunnels export | Editable ordered sections, three actual server routes, static preview ZIP, legacy graph/build brief | Not a freeform drag/drop funnel graph, proprietary template gallery or complete upsell/membership engine |
| Ask Iman AI bonus | Independent `ask` command using evidence brief | No likeness, private corpus or claim of equivalent training |
| Staff handpicked list/coaching/guarantees | Not reproduced | These are human/private services, not available software agents |

Core runtime is tested with fixtures and mocked provider contracts. A real ten-stage Ollama job completed; longer chapter-count coverage is fixture-tested, not a claim that every model/topic produces a publishable manuscript. See VALIDATION.md. No revenue is claimed by installation or tests.
