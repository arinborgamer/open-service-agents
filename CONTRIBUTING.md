# Contributing

Open an issue explaining the user problem and observable behavior. Small focused pull requests are welcome. Run the standard-library test suite before submitting. Add a meaningful regression test for payment, entitlement, job-state or privacy changes.

Keep providers replaceable, evidence attributed, and demo output explicit. Never add credentials, customer records, paid materials, downloaded transcripts or personal machine paths. Do not claim verified demand, earnings, inbox access or provider support without an actual implementation and evidence.

Use an alias and GitHub noreply commit address if desired. Avoid telemetry by default. When adding integrations, document credentials, scopes, limits, failure behavior and whether they were tested against a real sandbox.
